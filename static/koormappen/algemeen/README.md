In de map `/static/koormappen/algemeen` staan (directories met) bestanden
waarvan helder is dat ze op meerdere plekken gebruikt (kunnen) worden.

Het idee is ook dat ze kwalitatief zo goed zijn, dat ze gemakkelijk gebruikt
kunnen worden op meerdere plekken.

Bij het beheren van de inhoud van deze map moet er dan ook rekening mee worden
gehouden dat bestaande inhoud in verschillende koormappen gebruikt zouden 
kunnen worden, wat extra zorg van de beheerders vraagt, bijvoorbeeld bij
- het veranderen van bestandsnamen
